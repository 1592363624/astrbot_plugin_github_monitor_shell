# 2026-09-05

## Issues 动态通知支持图片（v1.4.1）

- 需求来源：smdz 仓库 Issue #8 的通知里，评论截图（GitHub user-attachments）在 QQ 中只显示为一串链接文字，用户希望图片以真图形式发送。
- 关键发现：GitHub 评论上传截图时正文实际是 HTML `<img src="...">` 标签（带 width/height 属性），不是 markdown `![]()`；两者都必须处理。
- 实现：
  - 新增 `utils/markdown_utils.py` 的 `extract_image_urls(text, max_images=6)`：识别三种格式——HTML img 标签、markdown 图片语法、常见扩展名裸图片直链（png/jpg/jpeg/gif/webp，可带查询参数），按出现顺序去重，正文原位置替换为 `[图片]` 占位符。
  - `main.py` `_check_repo_issues`：展示的前 3 条新评论提取图片（单条通知上限 6 张），文本通知发出后用 `MessageChain([Comp.Image.fromURL(u)...])` 补发图片消息（新增 `_send_issue_images` 辅助方法）；失败仅记日志不影响文本通知。
  - 发送链路已验证：aiocqhttp 平台对 Image 段会 `convert_to_base64()`（`MediaResolver` 下载 URL 转 base64），协议端无需能直连 GitHub。
- 版本 1.3.7 → 1.4.1（CHANGELOG 此前已记 1.4.0，metadata 漏更，本次对齐）。
- 用例测试：Issue #8 真实 HTML 格式、markdown 图片、混合去重、大小写/带 token 直链、纯文本——全部通过。
